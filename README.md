# Fumi Wu — academic personal site

A minimal Astro rebuild of the personal website at <https://fumiwu.github.io/>.
The homepage intentionally contains only Welcome, Focus, and Projects. Detailed
research information lives on stable project routes.

## Local development

```bash
npm install
npm run dev
npm run build
```

The site is static and deploys to GitHub Pages through
`.github/workflows/deploy.yml` after reviewed changes reach `master`.

The original Jekyll site is preserved at the Git reference
`backup/legacy-jekyll-20260918`.
